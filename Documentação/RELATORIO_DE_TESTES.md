# Relatório de Testes — PsiConnect

## 1. Objetivo

Este relatório apresenta os testes realizados no PsiConnect, sistema de gestão para atendimento psicológico, desenvolvido como projeto acadêmico.

O objetivo foi verificar o funcionamento das principais funcionalidades e as permissões de acesso de cada perfil.

## 2. Testes realizados

| Nº | Teste | Resultado |
|---|---|---|
| 01 | Login do administrador | Realizado |
| 02 | Login do psicólogo | Realizado |
| 03 | Visualização de pacientes pelo psicólogo | Realizado |
| 04 | Cadastro de paciente | Realizado |
| 05 | Cadastro de agendamento pelo administrador | Realizado |
| 06 | Login do atendente | Realizado |
| 07 | Acesso do atendente à agenda | Realizado |
| 08 | Acesso do administrador aos profissionais | Realizado |
| 09 | Formulário de cadastro de psicólogo | Verificado |
| 10 | Formulário de cadastro de atendente | Verificado |
| 11 | Registro de atividades | Verificado |
| 12 | Encerramento da sessão (logout) | Realizado |

## 3. Controle de acesso

Foram verificadas as permissões dos três perfis do sistema:

- **Administrador:** acesso à gestão de profissionais, pacientes, agenda e registro de atividades.
- **Atendente:** acesso à visão geral, aos pacientes e à agenda.
- **Psicólogo:** acesso aos pacientes vinculados e ao próprio perfil.

## 4. Evidências

As capturas de tela dos testes estão armazenadas na pasta `Evidências de Testes`, localizada na raiz do projeto.

## 5. Conclusão

Os testes realizados permitiram verificar as principais funcionalidades do PsiConnect, incluindo autenticação, gerenciamento de pacientes, agendamentos, controle de acesso e registro de atividades.

As evidências foram organizadas para documentar o funcionamento do sistema e auxiliar na avaliação do projeto acadêmico.
